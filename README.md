# SDG 4 – Kakovostno izobraževanje

Spletna galerija, posvečena 4. cilju trajnostnega razvoja: kakovostno izobraževanje za vse.

## Datoteke
- `index.html` – vsebina in kartice galerije
- `style.css` – postavitev, barve in odziven dizajn
- `script.js` – gumbi za deljenje, nazaj in prenos seznama fotografij

## Zagon
Odpri `index.html` v brskalniku ali objavi repozitorij z GitHub Pages.

Fotografije se nalagajo iz Unsplash, pisava pa iz Google Fonts, zato je za prikaz potreben dostop do interneta.
